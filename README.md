# 분원리 (가제)

한국 농촌 마을에 판타지가 스며든 2D 농장·크리처 육성 게임. Godot 4.7로 만든다.

## 지금 상태: 첫 프로토타입

그래픽은 임시다. 캐릭터, 슬라임, 농장 바닥, 마을 오브젝트는 코드로 그린 임시 스프라이트다 (`docs/sprites.md`, 생성기는 `tools/`). 핵심 순환이 재밌는지 확인하는 용도다.

```
농부로 시작 (마을 공급함에 알 1개가 들어 있음)
→ 손농사 (갈기 → 심기 → 물주기 → 수확)
→ 공급함에서 알 받기 → 부화기 → 집 현관에서 자고 나면 부화 (능력치와 Trait은 부화할 때 생성)
→ 첫 슬라임은 급수 담당. 밭 옆에 옮겨 놓으면 범위 안 작물에 물을 줌
→ 첫 슬라임을 배치하면 사냥꾼 조작이 열림
→ 사냥꾼이 사냥터 입구에서 F → 밭에 크리처가 있으면 누구랑 갈지 고름 (혼자도 됨) → 사냥터에서 야생 슬라임과 간단 전투 (구역: 1 분원농협 (화면 2x2 넓은 맵: 농협 창고 마당 · 철망 너머 논밭, 논에서는 사냥꾼이 느려짐, 야생 슬라임 7마리, 대장은 곳간 앞) → 2 금사리 (화면 2x2 넓은 맵, 카메라가 따라감. 냇물은 징검다리나 여울(느려짐)로 건너고, 화면 밖 가장 가까운 몬스터는 화면 가장자리 화살표로 알려 줌. 넓은 맵 두 구역 모두 오른쪽 위 작은 지도에 이번 사냥에서 가 본 곳만 보임. 모래톱에 숨은 모래게 6마리, 대장 금두꺼비는 25%로 금빛 알을 남김 → 아기 금두꺼비, 입구에 "금사리(구터)" 항아리 표지). 다 잡으면 대장, 대장을 쓰러뜨리면 위쪽 길로 같은 날 다음 구역, 금사리에 가면 웨이포인트가 켜져 다음 날부터 입구에서 거기서 시작), 데려간 크리처가 따라다니며 알아서 도움 (물 슬라임 물총 · 땅 슬라임 박치기 · 아기 금두꺼비 혀로 끌어와 멈춤, 밭에서 일하는 금두꺼비는 밤마다 사금을 주워 돈 5~15원, 하루 한 번, 알은 게임 첫 처치만 반드시 떨어지고 그 뒤로는 몬스터 3% · 대장 15~25%, 쓰러져도 주운 알은 그대로) → 쓰러뜨릴 때마다 20%로 돈 · 빨간 물약 · 슬라임 젤리 · 장비가 떨어짐 (디아블로2식 색 이름. 장비는 숲 공터 세트 조각(초록) 또는 등급을 굴린 장비: 일반 흰색 · 마법 파랑 옵션 1~2 · 레어 노랑 옵션 3~4. 칸이 비었으면 바로 입고 아니면 가방으로) → 마을 공급함 (알 넣기 · 젤리 팔기 · 장비 팔기: 일반 한꺼번에 · 가방에서 골라 팔기)
→ 이후 슬라임은 역할 없이 태어나고 R로 파종 / 급수 / 수확 중 지정
→ 수확한 무는 마을 공급함에 진열 → 밤사이 팔려 아침 카드에서 정산 → 공급함에서 씨앗 구입, 모은 돈으로 밭 넓히기 · 도구 손보기(넓은 괭이 · 큰 물뿌리개 · 사냥꾼 사냥칼) · 입는 장비(모자 · 옷 · 신발) · 크리처 훈련(크리처마다 범위 +1 · 속도 +25%, 단계마다 300 → 600 → 1200원)
```

## 실행

1. [Godot 4.7](https://godotengine.org/download) 설치
2. Godot에서 이 폴더의 `project.godot` 열기
3. F5로 실행

## 조작

| 키 | 동작 |
|---|---|
| WASD / 방향키 | 이동 |
| Space | 도구 사용 (농부), 사냥터에서는 사냥칼 휘두르기 (바라보는 쪽) |
| 마우스 왼쪽 클릭 | 사냥터에서 누른 쪽으로 사냥칼 휘두르기 |
| 1 | 사냥터에서 빨간 물약 마시기 (하트 +1) |
| Q / E | 도구 변경 |
| F | 상호작용 (공급함 선택창: W/S 고르기 · F 정하기 · Esc 닫기, 부화기, 사냥터 입구 들어가기(웨이포인트 · 동행 고르기 창) · 사냥터 위쪽 길에서 다음 구역 · 아래 입구에서 돌아오기, 슬라임 들기/내려놓기, 집 현관에서 잠자기) |
| R | 가까운 크리처가 맡을 일 바꾸기 |
| I | 가방 열기/닫기 (어디서나, 사냥터에서는 여는 동안 멈춤). 클릭 = 가방 장비 입기 · 입은 칸 벗기, WASD 칸 고르기 + F도 됨. 마을 창고 궤짝에서 F = 가방 + 공용 창고 (클릭 = 넣기/꺼내기, 오른쪽 클릭 또는 R = 입기) |
| Tab | 농부 ↔ 사냥꾼 전환 |
| N | 다음 날 (개발용, 디버그 빌드에서만) |

## 구조

- `scripts/config.gd` 모든 임시 수치 (확정값 아님)
- `scripts/game_state.gd` 전역 상태와 입력 등록 (autoload)
- `scripts/farm.gd` 밭 타일 상태와 농사 동작
- `scripts/character.gd` 농부·사냥꾼
- `scripts/creatures/` 크리처 시스템 (종, 속성, Trait, 개체, 일). 자세한 내용은 [docs/creatures.md](docs/creatures.md)
- `data/creatures/` 종·속성·Trait 데이터 파일
- `scripts/main.gd` 화면 구성과 상호작용
- `scripts/hunt_ground.gd` · `scripts/wild_slime.gd` 사냥터와 야생 슬라임 (간단 전투 첫 조각)
- `scripts/hunt_map.gd` 화면보다 넓은 사냥터의 칸 지도 (`data/hunt_maps/*.txt`, 바닥 그림은 `tools/make_hunt_maps.py`가 같은 지도로 `assets/hunt/`에 만듦)
- `scripts/hunt_loot.gd` 사냥터 드롭표 (20%: 돈 · 물약 · 잡템 · 장비)
- `scripts/hunt_companion.gd` 사냥터에 따라온 농장 크리처 (물 = 멀리서 물총, 땅 = 붙어서 박치기)
- `scripts/wearables.gd` 입는 장비 데이터와 가방 · 공용 창고 동작
- `scripts/inventory_ui.gd` 디아블로식 가방 창 (I 키, 창고 궤짝)
- `scripts/prop.gd` 마을 오브젝트 (부화기, 공급함, 사냥터 입구, 창고)
- `tests/smoke_test.tscn` 핵심 순환 자동 테스트
- `tests/playthrough.tscn` 새 게임을 며칠 자동으로 플레이하며 숫자를 남기는 점검 봇 (루프·밸런스 확인용, 통과/실패 없음)

## 테스트

```
godot --headless --path . --import
godot --headless --path . res://tests/smoke_test.tscn
# 며칠 자동 플레이 (DAYS 날 수, SEED 난수, OUT 로그 파일, CAPTURE 아침 카드 캡처 폴더)
DAYS=14 SEED=1 godot --headless --path . res://tests/playthrough.tscn
```

## 임시로 정해 둔 것 (기획 미확정)

- 마을 오브젝트 자리와 흙길 배치 (그림과 차지하는 칸 수는 결정됨)
- 작물은 물 준 날 3일이면 수확, 수확 시 씨앗 1개 반환
- 돈: 시작 0원, 무 1개 50원, 씨앗 5개 100원
- 밭: 네 구역(6x4) 중 처음엔 왼쪽 위 한 구역, 나머지는 공급함에서 300 → 500 → 800원에 연다
- 크리처 훈련: 공급함 → 크리처 훈련 ▶ 에서 크리처마다 범위(+1)·속도(+25%)를 3단계까지, 값은 300 → 600 → 1200원 (크리처·능력마다 따로). 훈련한 크리처는 일 이름 옆에 ★단계 합
- 도구 손보기: 넓은 괭이 200원 · 큰 물뿌리개 250원 (앞 3칸 일자), 사냥꾼 튼튼한 사냥칼 400원 (이후 태어나는 크리처 능력치 바닥 보장)
- 입는 장비: 공급함에서 사면 바로 입음. 농부 밀짚모자 80원(꾸미기) · 씨앗 주머니 조끼 300원(씨앗도 앞 3칸) · 장화 150원(걷기 +15%), 사냥꾼 캡모자 80원 · 등산화 150원(걷기 +15%)
- 사냥터 드롭 (공급함에서 안 팖): 숲 공터 세트 도토리 투구(하트 +1) · 숲지기 망토(휘두르기 범위 넓게) · 깃털 장화(걷기 +25%), 세트 완성 하트 +1 더. 드롭 20% (돈 40 · 물약 25 · 젤리 20 · 장비 15), 돈 10~30원, 젤리 15원
- 사냥 대체 동작: 하루 한 번, 알 1개 확정
- 분원농협 넓은 맵: 창고 마당 배치, 창고·철망·쌀 포대 그림, 슬라임 7마리, 논 걷기 60%, 작은 지도(가 본 곳 둘레 12x7칸)
- 금사리 넓은 맵: 52x30칸 배치 (모래톱 · 냇물 · 징검다리 · 여울 · 대장 모래밭 자리), 모래게 6마리, 여울 걷기 60%, 바닥 그림은 코드로 그린 임시
- 크리처 동행: 물총 사거리 110px · 1.6초, 박치기 1.0초 (개체 일 속도로 나눔), 크리처는 다치지 않음
- 시작 시 공급함의 알 1개 (첫 알 획득 이벤트는 나중에 정함)
- 사냥꾼 해금 조건: 첫 슬라임 배치
- 첫 슬라임 최저 능력치 보장: 속도 1.0 이상, 범위 2 이상
- 알은 1일 뒤 부화
- Trait 3종(평범함, 부지런함, 넓은 시야)과 능력치 범위
- 속성: 물(급수 재능 1.5배), 땅(파종 재능 1.5배), 비행(이동 1.6배). 슬라임은 물·땅 중 하나, 첫 슬라임은 물
