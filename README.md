# 분원리 (가제)

한국 농촌 마을에 판타지가 스며든 2D 농장·크리처 육성 게임. Godot 4.7로 만든다.

## 지금 상태: 첫 프로토타입

그래픽은 임시다. 캐릭터, 슬라임, 농장 바닥, 마을 오브젝트는 코드로 그린 임시 스프라이트다 (`docs/sprites.md`, 생성기는 `tools/`). 핵심 순환이 재밌는지 확인하는 용도다. 마을과 1구역 분원농협은 2026-09-30 그래픽 시범으로 한 단계 다듬었다: 픽셀 글꼴 갈무리9 (`assets/fonts`, SIL OFL 1.1) · 한지 창 · 아이콘 위 줄 · 시각별 빛 · 저녁 불빛 · 구름 그림자 · 날리는 잎.

```
농부로 시작 (마을 공급함에 알 1개가 들어 있음). 마을은 40x24칸 (화면 1.5배쯤) 이라 카메라가 조작 중인 캐릭터를 따라감: 위쪽 큰길에 밭 · 부화기 · 공급함 · 집 · 사냥터 입구, 아랫길에 대장간 · 약방 · 당산나무
→ 손농사 (갈기 → 심기 → 물주기 → 수확)
→ 하루 시계: 아침 6시에 일어나 위 줄 시계가 흐름 (게임 10분 = 실제 5초, 밤엔 조금 어두워지고 새벽 2시에서 멈춤). 시간 때문에 막히는 일은 없고, 하루는 집 현관에서 자야만 넘어감
→ 공급함에서 알 받기 → 부화기 → 집 현관에서 자고 나면 부화 (능력치와 Trait은 부화할 때 생성)
→ 첫 슬라임은 농사 담당. 밭 옆에 옮겨 놓으면 범위 안 밭을 수확 → 파종 → 급수 순으로 돌보고, 밭에 할 일이 없으면 풀밭으로 채집하러 감
→ 첫 슬라임을 배치하면 사냥꾼 조작이 열림
→ 사냥꾼이 사냥터 입구에서 F → 밭에 크리처가 있으면 누구랑 갈지 고름 (혼자도 됨) → 사냥터에서 야생 슬라임과 간단 전투 (구역: 1 분원농협 (화면 2x2 넓은 맵: 농협 창고 마당 · 철망 너머 논밭, 논에서는 사냥꾼이 느려짐, 야생 슬라임 7마리, 대장은 곳간 앞) → 2 금사리 (화면 2x2 넓은 맵, 카메라가 따라감. 냇물은 징검다리나 여울(느려짐)로 건너고, 화면 밖 가장 가까운 몬스터는 화면 가장자리 화살표로 알려 줌. 넓은 맵 두 구역 모두 오른쪽 위 작은 지도에 이번 사냥에서 가 본 곳만 보임. 모래톱에 숨은 요괴 모래게 6마리 (검붉은 가시 등딱지 · 톱니 집게 · 빨간 눈), 대장 금두꺼비는 25%로 금빛 알을 남김 → 아기 금두꺼비, 입구에 "금사리(구터)" 항아리 표지) → 3 광동리 (2막 첫 구역, 추수 벌판 · 짚가리 · 군량 곳간 · 배수로. 요괴 까마귀 떼는 날아다녀 칼이 안 닿고, 사냥꾼 발밑 그림자 원을 예고한 뒤 내려꽂음(하트 -2) → 비켜서 내려앉아 낟알을 쪼는 동안 치기. 대장 허수아비 장수는 짚단 셋을 차례로 던지고 두 번에 한 번 까마귀를 부름. 알은 아기 까마귀. 금사리 윗길 쇠다리가 끊겨 있어 대장간을 고쳐야 광동리로 건너감) → 4 도마리 (2막 마지막 구역, 나무꾼 벌목터 · 장작 쌓인 비닐하우스 · 장작더미 · 그루터기. 고목 그루터기는 진짜 그루터기 사이에 그루터기인 척 숨어 있다가 (가끔 눈이 번쩍) 가까이 가면 일어나 도끼로 달려듦. 2막 대장은 장승 한 쌍: 천하대장군은 긴 띠 예고 뒤 통나무를 굴리고, 지하여장군은 쿵 내려찍고 그루터기 새끼를 깨움, 둘 다 쓰러뜨려야 깸. 대장 알은 아기 나무 정령). 다 잡으면 대장, 대장을 쓰러뜨리면 위쪽 길로 같은 날 다음 구역, 금사리에 가면 웨이포인트가 켜져 다음 날부터 입구에서 거기서 시작), 몬스터는 가까이 오면 ! 와 바닥 붉은 띠로 예고한 뒤 돌진하니 옆으로 비켜서 헐떡일 때 치기 (금사리는 예고가 짧고 하트 -2 · 무리로 튀어나옴, 대장 슬라임은 그림자 원 내려찍기 + 새끼, 금두꺼비는 혀 채찍 + 밟으면 느려지는 금가루), 데려간 크리처가 따라다니며 알아서 도움 (물 슬라임 물총 · 땅 슬라임 박치기 · 아기 금두꺼비 혀로 끌어와 멈춤, 밭에서 일하는 금두꺼비는 밤마다 사금을 주워 돈 5~15원, 하루 한 번, 알은 게임 첫 처치만 반드시 떨어지고 그 뒤로는 몬스터 3% · 대장 15~25%, 쓰러져도 주운 알은 그대로) → 쓰러뜨릴 때마다 20%로 돈 · 빨간 물약 · 슬라임 젤리 · 장비가 떨어짐 (디아블로2식 색 이름. 장비는 숲 공터 세트 조각(초록) 또는 등급을 굴린 장비: 일반 흰색 · 마법 파랑 옵션 1~2 · 레어 노랑 옵션 3~4. 칸이 비었으면 바로 입고 아니면 가방으로) → 마을 공급함 (알 넣기 · 젤리 팔기 · 장비 팔기: 일반 한꺼번에 · 가방에서 골라 팔기)
→ 이후 슬라임은 역할 없이 태어나고 R로 농사 / 채집 중 지정 (농사: 범위 안 밭 일을 다 하고 한가하면 채집. 속도는 수확·파종·급수마다 속성 재능을 따름. 채집: 하루 종일 마을 풀밭 나물을 캐서 공급함에 진열, 땅속성은 손으로 못 캐는 도라지 뿌리도, 물속성은 캔 자리에 물을 줘 다음 날 나물이 더 돋음)
→ 수확한 무와 아침마다 밭 밖 풀밭에 돋는 들나물(냉이 · 쑥 · 달래, 가까이서 F로 캠)은 마을 공급함에 진열 → 밤사이 팔려 아침 카드에서 정산 → 공급함에서 씨앗 구입, 모은 돈으로 밭 넓히기 · 도구 손보기(넓은 괭이 · 큰 물뿌리개 · 사냥꾼 사냥칼) · 입는 장비(모자 · 옷 · 신발) · 크리처 훈련(크리처마다 범위 +1 · 속도 +25%, 단계마다 300 → 600 → 1200원)
→ 금사리 대장 금두꺼비를 처음 쓰러뜨린 다음 날, 마을 아랫길 왼쪽 풀밭에 무너진 대장간 터가 드러남. 금두꺼비를 잡을 때마다 사금 덩이 1개 → 터에서 F: 돈 2,000 · 들고 있는 무 40 · 사금 덩이 12를 다 모으면 한 번에 고침
→ 대장간을 고치면 대장장이(Tab 셋째 캐릭터)와 고물 더미가 생김. 고철은 고물 더미에서 F로 줍거나 크리처에게 고철 줍기(R, 땅속성이 빠름)를 맡김, 아침마다 6개 쌓임
→ 도마리 장승 한 쌍을 잡을 때마다 장승 조각 1개, 처음 잡은 다음 날 아랫길 가운데 풀밭에 무너진 약방 터가 드러남 (그 뒤로 땅 크리처가 캔 도라지는 약방에 모음). 터에서 F: 돈 4,000 · 도라지 20 · 장승 조각 20을 모으면 한 번에 고침 → 연금술사(Tab 넷째 캐릭터) · 도라지밭 (아침마다 6, 크리처에게 도라지밭(R)을 맡기면 캠, 불속성 2배). 연금술사가 약방에서 F → 빨간 물약 두 병 · 호롱 기름 (번천에서 호롱 불빛 넓게) · 힘 물약 (다음 사냥 피해 +1) · 빠르기 물약 (다음 사냥 걸음 +25%) · 크리처 보약 (그날 모든 크리처 일 두 배). 재료는 나물 · 도라지 · 사냥 잡템 · 무. 연금술사가 호롱을 만들어 줘야 도마리 윗길 너머 5구역 번천으로 감
→ 5 번천 (3막 첫 구역, 산과 도로뿐인 T자 삼거리 밤. 화면이 어둡고 가로등 · 사냥꾼 호롱 · 동행 불빛만 밝음. 도깨비불은 유령이라 불빛 밖에선 반쯤 비쳐 칼 · 화살이 지나가고 몸도 안 닿음, 불빛 안에 들어오면 부풀었다가 불똥을 튀김 (원 예고), 쪼그라든 동안 칠 틈. 대장 유령 막차는 전조등으로 도로 띠를 비춘 뒤 돌진하고 두 번에 한 번 도깨비불 승객을 내림. 알은 아기 도깨비불)
→ 6 밀목 (3막 둘째 구역, 나무가 빽빽한 소나무 숲. 그늘이라 어둡기만 하고 불빛 규칙은 없음. 그림자 늑대 무리는 사냥꾼을 보면 둘레에 둘러서서 돌다가 하나씩 웅크렸다 달려듦, 한 마리를 쓰러뜨리면 가까운 늑대가 움찔. 대장 산군 백호는 덮치기 (원 예고) · 앞발로 나무 쓰러뜨리기 (띠 예고) · 포효 (원 안이면 몸이 1초 굳음)를 번갈아 씀. 알은 아기 호랑이, 드물게 (10%) 아기 백호)
→ 산군 백호를 잡을 때마다 산군 발톱 1개, 처음 잡은 다음 날 부화기 오른쪽 큰길 위에 무너진 축사 터가 드러남. 터에서 F: 돈 6,000 · 무 60 · 산군 발톱 20을 모으면 한 번에 고침 → 목축인(Tab 다섯째 캐릭터) · 닭 한 쌍. 닭장에서 F: 모이 주기 (무 1, 모이 먹은 암탉은 아침마다 달걀 하나, 굶으면 반쯤) · 둥지 달걀 꺼내기 (꺼내지 않은 달걀은 밤에 반쯤 병아리가 되고 3일 뒤 암탉, 8마리까지) · 사냥 도시락 (목축인만, 달걀 2 · 무 1 → 다음 사냥 하트 +2). 달걀은 공급함에 진열해 팖. 크리처에게 모이 주기(R)를 맡기면 무 없이 먹이고, 아기 호랑이 · 아기 백호가 맡으면 족제비도 안 옴 (지킴이가 없으면 가끔 밤에 둥지 달걀이나 병아리를 물어 감). 가축은 번식하지만 크리처 알은 늘 야생에서만 나옴
→ 7 역동 (4막 첫 구역, 옛 경안역 역참 · 넓은 말 들판 · 마방. 밀목 윗길 목책은 축사를 고쳐야 열림. 켄타우로스 창기병은 발을 구르며 긴 띠를 예고하고 들판을 가로질러 돌격, 지나친 뒤 돌아서는 동안이 칠 틈. 대장 역마 장군은 사냥꾼 쪽으로 꺾이는 창 돌격 세 번 → 헐떡임, 두 번에 한 번 파발 나팔로 창기병 둘, 체력 절반부터 돌격 앞에 말발굽 쿵. 알은 아기 망아지)
→ 대장장이가 모루에서 F → 고철 + 돈으로 현대풍 장비 제작 (농부: 작업 모자 · 방수 작업복 · 작업 장화, 사냥꾼: 안전모 · 등산 조끼 · 안전화). 만들 때마다 디아블로2 제작처럼 옵션 1~3개 무작위 (농부: 걷기 · 씨앗 칸 + · 괭이 · 물뿌리개 칸 +, 사냥꾼: 사냥터 장비 옵션과 같음), 주황 "제작" 등급. 칸이 비었으면 바로 입고 아니면 그 사람 가방으로, 필요 없으면 공급함에서 40원에 팜
```

## 실행

1. [Godot 4.7](https://godotengine.org/download) 설치
2. Godot에서 이 폴더의 `project.godot` 열기
3. F5로 실행
4. 먼저 **처음 화면**이 뜬다: 슬롯 1~3 중 고른다 (쓴 슬롯 = 날짜 · 돈 · 이어하기, 빈 슬롯 = 새 게임, 슬롯 지우기는 같은 슬롯을 두 번 F). 잘 때 아침이 되면 · 사냥터에서 돌아오면 저절로 저장하고, Esc 멈춤 메뉴의 **저장하고 나가기**로 언제든 저장한다 (사냥터 안이면 마을로 돌아온 채로). 저장 파일은 `user://save_<슬롯>.sav`
5. 개발용 빌드(에디터 F5)에서 빈 슬롯의 새 게임을 고르면 **테스트용 시작 지점** 창이 이어서 뜬다: 처음부터 · 사냥꾼 막 열림 · 5일째 · 대장간 고치기 직전 · 20일째 대장간 복구 뒤 · 30일째 도마리 앞 · 45일째 3막 입구 (약방 고친 뒤, 번천 웨이포인트) · 55일째 밀목 앞 (밀목 웨이포인트) · 70일째 축사 복구 뒤 (목축인 · 암탉 3 · 도시락 1 · 모이 주는 아기 호랑이) · 75일째 역동 앞 (역동 웨이포인트 · 도시락 2). 숫자키나 W/S + F로 고르고, Esc는 처음부터. 저장이 아니라 그 시점쯤의 상태(돈 · 밭 · 크리처 · 장비 · 무기 · 웨이포인트 · 대장간)를 매번 새로 채운다. 정식(릴리스) 빌드에서는 안 뜬다

## 조작

| 키 | 동작 |
|---|---|
| WASD / 방향키 | 이동 |
| Space | 도구 사용 (농부), 사냥터에서는 구르기 (걷는 쪽으로 휙, 그동안 안 맞음. Shift 도 같음) |
| J | 사냥터에서 바라보는 쪽으로 공격 |
| 마우스 왼쪽 클릭 | 사냥터에서 누른 쪽으로 공격 (꾹 누르면 계속): 무기 칸이 비면 사냥칼 휘두르기, 근거리 무기는 더 넓게 · 빠르게, 활은 화살, 지팡이는 속성 구슬. 근거리는 이어 베면 1 · 2 · 3타, 3타째는 넓고 피해 +1 |
| 마우스 오른쪽 클릭 | 사냥터에서 든 무기의 큰 스킬 (찍었으면): 검 대지 가르기 · 활 화살비 · 지팡이 원소 폭풍 |
| 1 | 사냥터에서 빨간 물약 마시기 (하트 +1) |
| Q / E | 도구 변경, 사냥터에서는 왼클릭 공격 방식 바꾸기 (찍은 스킬 중: 회전 베기 · 관통 화살 · 부채살 · 3연사 · 연쇄 구슬) |
| T | 사냥꾼 스킬 창 (어디서나, 사냥터에서는 여는 동안 멈춤). 클릭 또는 WASD + F 로 한 단계 찍기 |
| F | 상호작용 (대장간 터: 복구 창 · 대장간 모루: 대장장이 제작 창 · 고물 더미: 고철 줍기, 약방 터: 복구 창 · 약방: 연금술사 제작 창 · 도라지밭: 도라지 캐기, 축사 터: 복구 창 · 닭장: 모이 · 달걀 · 도시락 창, 공급함 선택창: W/S 고르기 · F 정하기 · Esc 닫기, 부화기, 사냥터 입구 들어가기(웨이포인트 · 동행 고르기 창) · 사냥터 위쪽 길에서 다음 구역 · 아래 입구에서 돌아오기, 슬라임 들기/내려놓기, 들나물 캐기, 집 현관에서 잠자기) |
| R | 가까운 크리처가 맡을 일 바꾸기, 사냥터에서는 조련 돌격 명령 (동행이 마우스 가까운 몬스터에 달려감) |
| I | 가방 열기/닫기 (어디서나, 사냥터에서는 여는 동안 멈춤). 클릭 = 가방 장비 입기 · 입은 칸 벗기, WASD 칸 고르기 + F도 됨. 마을 창고 궤짝에서 F = 가방 + 공용 창고 (클릭 = 넣기/꺼내기, 오른쪽 클릭 또는 R = 입기) |
| Tab | 캐릭터 전환 (농부 → 사냥꾼 → 대장간을 고치면 대장장이 → 약방을 고치면 연금술사 → 축사를 고치면 목축인) |
| N | 다음 날 (개발용, 디버그 빌드에서만) |
| Esc | 선택창 닫기, 아무 창도 없으면 멈춤 메뉴 (계속하기 · 저장하고 나가기) |

## 구조

- `scripts/config.gd` 모든 임시 수치 (확정값 아님)
- `scripts/game_state.gd` 전역 상태와 입력 등록 (autoload)
- `scripts/farm.gd` 밭 타일 상태와 농사 동작
- `scripts/character.gd` 농부·사냥꾼
- `scripts/creatures/` 크리처 시스템 (종, 속성, Trait, 개체, 일). 자세한 내용은 [docs/creatures.md](docs/creatures.md)
- `data/creatures/` 종·속성·Trait 데이터 파일
- `scripts/main.gd` 화면 구성과 상호작용
- `scripts/hunt_ground.gd` · `scripts/wild_slime.gd` 사냥터와 야생 슬라임 (간단 전투 첫 조각)
- `scripts/hunt_map.gd` 화면보다 넓은 사냥터의 칸 지도 (`data/hunt_maps/*.txt`, 바닥 그림은 `tools/make_hunt_maps.py`가 같은 지도로 `assets/hunt/`에 만듦)
- `scripts/hunt_loot.gd` 사냥터 드롭표 (20%: 돈 · 물약 · 잡템 · 장비)
- `scripts/hunt_companion.gd` 사냥터에 따라온 농장 크리처 (물 = 멀리서 물총, 땅 = 붙어서 박치기)
- `scripts/wearables.gd` 입는 장비 데이터와 가방 · 공용 창고 동작
- `scripts/inventory_ui.gd` 디아블로식 가방 창 (I 키, 창고 궤짝)
- `scripts/forage.gd` 밭 밖 풀밭의 들나물 · 땅속 도라지 뿌리 · 물 준 풀밭 (아침마다 돋음, 임시 그림)
- `scripts/hunter_skills.gd` 사냥꾼 레벨 · 경험치 · 스킬 판 (디아2식, 검 · 활 · 지팡이 · 조련 트리), `scripts/skill_panel.gd` 스킬 창 (T)
- `scripts/save_game.gd` 저장/불러오기 (슬롯 3, GameState 변수 전부 + 밭 · 풀밭 · 크리처 · 부화기 · 캐릭터 자리)
- `scripts/test_starts.gd` 테스트용 시작 지점 (개발용 빌드에서만, 시점마다 채울 상태 표)
- `scripts/prop.gd` 마을 오브젝트 (부화기, 공급함, 사냥터 입구, 창고, 대장간, 고물 더미)
- `tests/smoke_test.tscn` 핵심 순환 자동 테스트
- `tests/playthrough.tscn` 새 게임을 며칠 자동으로 플레이하며 숫자를 남기는 점검 봇 (루프·밸런스 확인용, 통과/실패 없음)
